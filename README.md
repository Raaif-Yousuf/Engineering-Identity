# Engineering Identity

Predicting a composite engineering identity score (-50 to +50) for first-year engineering students from concept-map, verification, definition, and survey metrics.

Real study data is not stored in this repo; it is read from `EI_DATA_DIR` at runtime. See [`docs/data.md`](docs/data.md) for the data card (aggregates only).

More to come as the model and evaluation code land.
