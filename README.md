# Engineering Identity

Predicting first-year engineering students' composite engineering identity score (-50 to +50) from what they say and draw: a start- and end-of-semester survey, three written definitions of an engineer, and a hand-drawn concept map turned into 29 graph-complexity metrics.

This rebuilds a study I worked on at UT Dallas (Aug 2024 - Jun 2025, ~1,900 students) so its results can be reproduced and checked. The original pipeline was a MATLAB "wisdom of the crowd" ensemble (189 architectures x 100 replications) and a Keras ANN I wrote. Both are reimplemented here and scored the same way, on the same folds.

## Why it exists

The original numbers were never reproducible: the MATLAB result that ended up in the paper draft has no surviving predictions to check it against, and several reported scores don't recompute from the saved outputs. Two things came out of rebuilding it:

- **Seven of the input columns are part of the score being predicted.** They are the survey's own identity items. Adding them up, with no model at all, already explains a third of the variance. Every model here is therefore run twice, with and without them.
- **The honest version of the task is prediction, not fitting**: start-of-semester answers predicting the end-of-semester score.

Results land in [`docs/experiments.md`](docs/experiments.md) as they finish.

## Data

The study data is human-subjects research data and is not in this repo, ever. The code reads de-identified tables from `EI_DATA_DIR`; tests run on synthetic data generated by `tests/fixtures/synthetic.py`. [`docs/data.md`](docs/data.md) describes the tables in aggregate only.

## Run it

```bash
pip install -e ".[dev]"
pytest
EI_DATA_DIR=/path/to/tables python -m ei_model.experiments run --config configs/replication.yaml
```
